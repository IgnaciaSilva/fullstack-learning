# 🌳 DevTree - Primeros pasos

## Descripción del proyecto

DevTree es el primer proyecto Full Stack desarrollado durante el curso.

El objetivo es construir una aplicación utilizando tecnologías modernas de backend y frontend.

## Tecnologías del proyecto

Backend:

- Node.js
- Express
- TypeScript

Base de datos:

- MongoDB

Frontend:

- React con Vite

---

# Configuración inicial

## Creación del proyecto Node.js

Se creó un nuevo proyecto utilizando Node.js y npm para gestionar dependencias.

## Servidor con Express

Express permite crear un servidor web utilizando Node.js.

Conceptos aprendidos:

- Crear un servidor.
- Escuchar peticiones HTTP.
- Configurar rutas.

## Modo Watch

Se configuró el modo watch para reiniciar automáticamente el servidor al detectar cambios.

Herramientas utilizadas:

- Node.js watch mode.
- Nodemon.

## Sintaxis ESM

Se habilitó el uso de módulos ES (ES Modules) en Node.js.

Esto permite utilizar:

```javascript
import
export

en lugar de:
