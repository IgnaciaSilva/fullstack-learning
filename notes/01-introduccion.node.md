# Introducción a Node.js

## ¿Qué es Node.js?

Node.js es un entorno de ejecución que permite utilizar JavaScript fuera del navegador, ejemplo ya sea web, escritorio o movil, etc.

Utiliza el motor JavaScript V8 el nucleo de Google Chrome fuera del navegador, permite crear aplicaciones del lado del servidor y tambien que node.js tenga un alto rendimiento.

## Ventajas de Node.js

Se puede utilizar en web como App Monolítica o como API.
NPM con una gran cantidad de paquetes.
Gran adopcion de la comunidad.

## Instalación de Node.js

Para trabajar con Node.js es necesario instalar:

- Node.js
- npm (Node Package Manager)

npm permite instalar y administrar paquetes necesarios para nuestros proyectos.

## Frameworks de Node.js

Algunos frameworks populares:

- Express.js
- NestJS
- Fastify
- AdonisJS
- Sails.js
- Etc

Estos frameworks ayudan a crear aplicaciones backend de manera más organizada.

## ¿Qué es Express?

Express.js es un framework minimalista para Node.js utilizado para crear servidores y APIs.

Ventajas:

- Fácil de aprender.
- Flexible.
- Gran comunidad.
- Permite crear rutas y manejar peticiones HTTP.
